# NixOS Desktop: Hyprland

The NixOS desktop runs Hyprland, started from the ReGreet login screen, with a
Quickshell status bar, hyprpaper for the wallpaper and Vicinae as a
Raycast-like launcher. Everything is declared in this repository; nothing is
configured by hand on the machine.

Colors follow Catppuccin Mocha, like Ghostty and the macOS setup.

## Startup

1. Limine shows the boot menu (see [Boot menu](#boot-menu-limine)).
2. Systemd starts greetd, the display manager. It runs a minimal Hyprland as
   the `greeter` user with `modules/nixos/greetd/hyprland.lua`, which enables
   only the LG main monitor (DP-2), disables the ultrawide and starts ReGreet.
   ReGreet fullscreens on the first monitor it finds, so this keeps the login
   screen on the LG; the NixOS module's default Cage kiosk cannot choose an
   output by name. When ReGreet exits, the greeter's Hyprland exits too.
3. ReGreet lists the sessions installed by `programs.hyprland` and remembers
   the last user and session in `/var/lib/regreet`. Choosing Hyprland starts
   it without UWSM (`withUWSM = false`).
4. `~/.config/hypr/hyprland.lua`, generated by Home Manager, imports the
   session environment into systemd and D-Bus and starts
   `hyprland-session.target`, which is bound to `graphical-session.target`.
5. User services attached to those targets start: hyprpaper, Quickshell,
   the Vicinae server and the Hyprland polkit agent. No program is started
   with `exec_cmd` from the Hyprland configuration.

Check the services with `systemctl --user status hyprpaper quickshell vicinae
hyprpolkitagent`, and the greeter with `systemctl status greetd` and
`/var/log/regreet/log`.

If the LG is not connected, the ultrawide stays disabled and the login screen
is not visible; use a text console (Ctrl+Alt+F2) or connect the LG. Change the
monitor rules in `greetd/hyprland.lua` together with
`home/xhan/linux/hyprland/monitors.lua`.

## Login screen: ReGreet

ReGreet reads `/etc/greetd/regreet.toml` and `/etc/greetd/regreet.css`, both
generated by the `programs.regreet` module from `modules/nixos/greetd.nix`:

- GTK theme: Magnetic Catppuccin (`magnetic-catppuccin-gtk`, mauve accent,
  dark), a flat theme with rounded widgets and GTK 4 support; Papirus dark
  icons, the Catppuccin cursor and JetBrains Mono.
- `greetd/regreet.css` restyles ReGreet's widgets: a floating rounded login
  card and clock panel, rounded inputs with a mauve focus ring, a mauve Login
  button and pill-shaped Reboot/Power Off buttons that turn red on hover. The
  panels are opaque: GTK cannot blur the wallpaper behind them, and with
  transparency the wallpaper's logo shows through.
- Background: the shared wallpaper in `wallpapers/`.
- Clock: weekday, date and time. ReGreet ignores a format string that
  contains non-ASCII characters and falls back to its default.

To preview a change without logging out, run ReGreet in demo mode inside any
Wayland session on the NixOS machine:

```bash
regreet --demo -c /etc/greetd/regreet.toml -s /path/to/regreet.css -l /tmp/regreet.log
```

The demo lists no sessions unless `XDG_DATA_DIRS` contains the NixOS session
files; the real greeter receives them from its PAM session.

## Boot menu: Limine

`modules/nixos/boot.nix` styles Limine with Catppuccin Mocha: the shared
wallpaper, blurred and darkened at build time with ImageMagick, a mauve
`NixOS` title, blue help text, a translucent text panel with a soft edge
(`term_margin`, `term_margin_gradient`), Catppuccin terminal palettes and
double-size font for the 1440p monitors. The options map to Limine's
`CONFIG.md`; `term_background` is `TTRRGGBB`, where a higher `TT` is more
transparent.

The menu lists the newest generation as the first, default entry,
`NixOS (generation N)`. Older generations (up to `maxGenerations`) are in a
collapsed **Previous generations** submenu, followed by Windows 11.

The NixOS Limine module always nests every generation in one expanded
directory and has no option to change this, so
`modules/nixos/limine-generations.nix` patches its install script with
`modules/nixos/limine/generations.patch`. The module takes the upstream
script, with its configuration already substituted, from the NixOS Limine
module itself and replaces `system.build.installBootLoader`, so every
`boot.loader.limine` option keeps working. If a Nixpkgs update changes the
script so the patch no longer applies, the system build fails instead of the
boot menu; refresh the patch against the new
`nixos/modules/system/boot/loader/limine/limine-install.py`.

The menu is written to `/boot/limine/limine.conf` on activation; check it
there after `nixos-rebuild switch`.

## Hyprland configuration

Hyprland 0.55 replaced `hyprland.conf` with a Lua configuration. With
`home.stateVersion = "26.05"` the Home Manager module writes
`~/.config/hypr/hyprland.lua` (`configType = "lua"`). Its only content is the
systemd startup hook and a list of `require` calls.

The configuration itself is plain Lua in `home/xhan/linux/hyprland/`,
installed read-only as `~/.config/hypr/conf/`. Hyprland adds its config
directory to the Lua module path, so `require("conf.keybinds")` loads
`conf/keybinds.lua`.

| File | Contents |
| --- | --- |
| `env.lua` | Environment variables: cursor theme and size, `NIXOS_OZONE_WL` for Electron apps. |
| `monitors.lua` | DP-2 (LG UltraGear, 2560×1440, left, main) and DP-3 (3440×1440 ultrawide, right), highest refresh rate; a fallback for other outputs. |
| `workspaces.lua` | Workspaces 1–5 on DP-2 (LG), 6–9 on DP-3, all persistent. |
| `input.lua` | US layout, Caps Lock as Control (as on the MacBook), key repeat, flat mouse acceleration. |
| `appearance.lua` | Gaps, borders, rounding, blur, shadows, animations and misc options. |
| `windowrules.lua` | Window rules (Spotify on workspace 8, floating dialogs and utilities, picture-in-picture) and the layer rule that blurs the bar. |
| `keybinds.lua` | Key bindings, listed below. |

Packages and Hyprland itself come from `programs.hyprland` on the system
side, so the Home Manager module has `package = null` and
`portalPackage = null`.

Since the files are Nix store links, change them in the repository and
activate; Hyprland reloads automatically when the files change. To check the
configuration before activating, copy the generated `hyprland.lua` and the
`conf/` directory to a temporary directory on the NixOS machine and run:

```bash
Hyprland --verify-config -c /path/to/hyprland.lua
```

It reports unknown fields and invalid dispatcher arguments with their file
and line.

The Hyprland API is described by the Lua stubs shipped with the package
(`share/hypr/stubs/hl.meta.lua`) and by the [Hyprland wiki](https://wiki.hypr.land/).
`hyprctl dispatch` now takes a Lua dispatcher expression, for example
`hyprctl dispatch 'hl.dsp.focus({ workspace = 3 })'`.

## Wallpaper

hyprpaper draws `wallpapers/nixos-wallpaper-catppuccin-mocha.png`, copied into
the Nix store, on every monitor (`monitor = ""` matches all outputs) with
`fit_mode = "cover"`. Home Manager writes `~/.config/hypr/hyprpaper.conf` and
the `hyprpaper` user service. Hyprland's own default wallpaper and logo are
disabled in `appearance.lua`.

## Status bar: Quickshell

Quickshell is a QtQuick shell toolkit; the bar is written in QML in
`home/xhan/linux/quickshell/` and installed as `~/.config/quickshell/bar`
(`programs.quickshell.activeConfig = "bar"`). The `quickshell` user service
starts with `hyprland-session.target`. `quickshell.nix` adds a generated
`Scripts.qml` singleton to the installed copy, holding the store paths of the
network scripts described below.

| File | Contents |
| --- | --- |
| `shell.qml` | Entry point: one `Bar` per screen. |
| `Theme.qml` | Colors, font and sizes (singleton). |
| `Bar.qml` | Floating top bar; layer-shell namespace `quickshell-bar`. |
| `Workspaces.qml` | Hyprland workspaces of that monitor; click to switch. |
| `ActiveWindow.qml` | Title of the focused window. |
| `Clock.qml` | Date and time. |
| `Media.qml` | Track of the playing (or else paused) MPRIS player, e.g. Spotify or a browser; hidden when there is none. Click to play or pause, scroll to skip, right click for `MediaPanel.qml`. |
| `MediaPanel.qml` | Player card: cover (click to raise the player), title, artist, album, seekable progress bar, previous/play/next. |
| `Network.qml` | Icon of the active connection (Ethernet preferred, Wi-Fi with signal strength, red when offline, peach when connectivity is limited) and upload/download rate of the default-route interface. Click for `NetworkPanel.qml`. |
| `NetworkPanel.qml` | Connection details (interface, link speed or signal) and traffic by process, refreshed every 1.5 s while open. |
| `BarPopup.qml` | Dropdown card used by both panels; clicking outside it and the bar closes it (`HyprlandFocusGrab`). |
| `Tray.qml` | System tray; left click activates, right click opens the menu. |
| `Volume.qml` | Default PipeWire output; scroll to change, click to mute, right click opens pwvucontrol. |

Quickshell 0.3 detects the Lua configuration and sends Lua dispatchers to
Hyprland when a workspace is clicked. Logs are available with
`journalctl --user -u quickshell`. To try changes without activating, build
the installed copy and run it inside the Hyprland session (stop the service
first):

```sh
quickshell -p "$(nix build --no-link --print-out-paths \
  .#nixosConfigurations.nixos.config.home-manager.users.xhan.programs.quickshell.configs.bar)"
```

The connection state comes from NetworkManager through
`Quickshell.Networking`, the track from MPRIS through
`Quickshell.Services.Mpris`. Traffic is measured by the two scripts of
[egoist/omarchy-network-throughput](https://github.com/egoist/omarchy-network-throughput)
(MIT), pinned by commit in `quickshell.nix` and wrapped with their
dependencies (GNU awk, iproute2, jq, coreutils):

- `network-throughput` samples `/sys/class/net/<iface>/statistics` of the
  default-route interface over 0.75 s; the bar runs it every second.
- `process-throughput` samples per-socket TCP counters with `ss -tinp` and
  attributes them to processes, without root. Traffic it cannot attribute
  (UDP and HTTP/3, other users' and system services, short-lived sockets) is
  the "Other traffic" row. The panel's row-keeping rules are adapted from
  the same project's panel; its Omarchy-specific QML is not used.

To update the scripts, change `rev` and `hash` of `fetchFromGitHub` in
`quickshell.nix`.

## Launcher: Vicinae

[Vicinae](https://docs.vicinae.com) is the Raycast equivalent on Linux:
application search, calculator, clipboard history, emoji picker, file search,
window switching and support for Raycast extensions. Its server runs as the
`vicinae` user service and Super+Space runs `vicinae toggle`, like
Command+Space for Raycast on the MacBook.

`home/xhan/linux/vicinae.nix` writes `~/.config/vicinae/settings.json`: the
built-in Catppuccin Mocha theme, the JetBrains Mono Nerd Font, Escape closes
the window, and system information telemetry is disabled. Settings changed in
the Vicinae UI are overwritten by the next activation. Extensions can be added
declaratively through `programs.vicinae.extensions`.

## Theme

`home/xhan/linux/theme.nix` installs the Catppuccin Mocha dark cursor (also set
for Hyprland in `env.lua`), the Magnetic Catppuccin GTK theme, Papirus dark
icons and the `prefer-dark` color scheme, which needs `programs.dconf.enable`
in `modules/nixos/hyprland.nix`. The greeter uses the same theme, icons,
cursor and font.

## Shell and terminal

Fish is the login shell (`users.users.xhan.shell` in
`modules/nixos/users.nix`); `programs.fish.enable` on the system side adds it
to `/etc/shells` and sets up the NixOS environment. Its user configuration and
Starship are shared with the Mac in `home/xhan/common/fish.nix`. Ghostty is
installed from Nixpkgs with the shared configuration
(`home/xhan/linux/ghostty.nix`).

## Shared applications

`home/xhan/linux/apps.nix` installs the Linux versions of applications the
MacBook gets from Homebrew: Discord, Obsidian, Spotify, Zed, Claude Code, tmux, tuios
and mkcert. The browser remains Chromium (`home/xhan/linux/chromium.nix`).
Unfree packages are allowed by name in `modules/nixos/nixpkgs.nix`.
ZenNotes, Zen, Helium, ChatGPT, the Claude desktop app and ArtCraft are not
packaged in Nixpkgs and are not installed.

## Activation

Build first, then activate from a terminal on the NixOS machine:

```bash
nix build ~/nix-config#nixosConfigurations.nixos.config.system.build.toplevel --no-link
```

```bash
sudo nixos-rebuild switch --flake ~/nix-config#nixos
```

Switching starts greetd immediately on its virtual terminal. A session already
running on tty1 is not closed; after logging out of it, or after a reboot,
the ReGreet login screen is shown. If the greeter fails, switch to another
virtual terminal with Ctrl+Alt+F2, log in, and inspect `journalctl -u greetd`.
The previous generation stays available in the Limine boot menu under
Previous generations.
